# L.U.N.A.R.

A minimal, phone-first Genshin Impact Primogem tracker for Android.

## Core tracker

- **Current Primogems** — the only value entered manually.
- **Weekly Goal** — 1,600 Primogems.
- **Grand Goal** — 200,000 Primogems.
- Weekly progress is calculated from the saved balance at the start of the tracked week.
- Progress is stored locally on the device.

The Android app is a lightweight WebView wrapper around the tracker in `app/src/main/assets`.
